A full-stack schedule and task management application designed to handle personal events, academic schedules, and part-time job income tracking. This project is currently under active development as I build out the core architecture and refine the user interface from scratch. 

Tech Stack
- Frontend: Fulluter(Dart) for cross-platform mobile compatibility(iOS/Android).
- Backend: Java with Spring Boot for REST API operations and business logic. 
- Database: H2/MySQL
- Deployment: Backend deployed on Render for 24/7 availability.

Core Features
- Dynamic Event Management: Create, read, update, and delete calendar events using a custom DailyEvent data model containing ID, Title, Memo, Start/End Time, and Event Type.
- Color-Coded Event Types: Events are categorized and color-coded by type, including Task, Birthday, Class, Job, and Personal.
- Financial Tracking(in-progress): A dedicated job schedule module to track shifts, calculate gross/net income, and automatically estimate taxes.
- Task & Reminder System(in-progress): Integrated task lists with auto-fill capabilities.
